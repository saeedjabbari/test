# طرح جامع تجربه تمام‌صفحه و بنر هوشمند نصب (Vercel Standalone PWA)

این طرح برای تبدیل وب‌اپلیکیشن مراکز درمانی کارآفرین به یک اپلیکیشن کاملاً تمام‌صفحه و بومی (Full-Screen Standalone Native-Like PWA) هنگام استقرار در ورسل (Vercel) و دسترسی کاربران موبایل و دسکتاپ تدوین شده است.

---

## بررسی کاربر و تصمیم‌های کلیدی

> [!IMPORTANT]
> با توجه به پاسخ‌های شما در مرحله اول گفت‌وگو، دو تصمیم محوری زیر مبنای ساخت قرار گرفته‌اند:

* **تصمیم تایید شده ۱ (حالت نمایش):** فعال‌سازی تجربه تمام‌صفحه مستقل (`standalone / full-screen`) بدون نوار آدرس و ابزارهای مزاحم مرورگر.
* **تصمیم تایید شده ۲ (شیوه دعوت به نصب):** پیاده‌سازی **بنر هوشمند شناور در پایین صفحه (Bottom Banner)** با کلید نصب مستقیم یک‌کلیکه برای اندروید و راهنمای خودکار برای آیفون (iOS)، با قابلیت ذخیره وضعیت رد کردن (Dismiss).
* **بهینه‌سازی ویژه سرور ورسل (Vercel):** تنظیم فایل پیکربندی `vercel.json` جهت مدیریت کش هدرهای Service Worker و مانیفست برای به‌روزرسانی بدون وقفه، و ریدایرکت‌های کامل SPA.

---

## ۱. مرور کلی و مفهوم اصلی (Overview & Core Concept)

### هدف محصول
کاربرانی که لینک ورسل (`https://....vercel.app`) یا دامنه اختصاصی را باز می‌کنند، به جای احساس وب‌سایت سنتی با نوار آدرس مرورگر، پیامی متناسب دریافت می‌کنند که برنامه را با یک لمس به صفحه اصلی گوشی اضافه کنند. پس از افزودن، اپلیکیشن با آیکون مستقل باز شده و تمام فضای صفحه (شامل Notch و لبه‌های مدرن نمایشگر) را با ظاهری نرم‌افزاری پوشش می‌دهد.

### مخاطبان هدف
بیمه‌گذاران، مراجعان به مراکز درمانی و نمایندگان بیمه کارآفرین که نیازمند دسترسی سریع و آفلاین به مراکز پزشکی بدون درگیر شدن با نوار جستجوی مرورگر هستند.

## ۲. تجربه کاربری و طراحی بصری (UX & Visual Design)

### جریان تعاملی کاربر (User Journey)
1. **ورود اولیه به ورسل:** کاربر لینک برنامه را در مرورگر کروم، سامسونگ، سافاری یا فایرفاکس باز می‌کند.
2. **بررسی وضعیت نصب:** اگر برنامه قبلاً نصب نشده باشد، پس از ۱٫۵ ثانیه یک بنر شیک و نرم از پایین صفحه ظاهر می‌شود.
3. **محتوای بنر شناور:**
   * آیکون رسمی اپلیکیشن بیمه کارآفرین با سایه ملایم و رزولوشن بالا.
   * تیتر واضح: **«نصب اپلیکیشن مراکز درمانی»**
   * زیرنویس تشریحی: **«دسترسی سریع، آفلاین و تمام‌صفحه بدون نوار آدرس»**
   * دکمه اقدام اصلی: **«نصب سریع (یک‌کلیک)»**
   * دکمه بستن: آیکون ضربدر ظریف جهت بستن بنر بدون آزار کاربر.
4. **رفتار پس از نصب:** به محض نصب برنامه یا باز شدن در محیط Standalone، بنر به طور خودکار محو می‌شود و هرگز دوباره نشان داده نخواهد شد.

```
┌────────────────────────────────────────────────────────┐
│  [لوگو] مراکز درمانی کارآفرین ارومیه          [فیلترها]│
├────────────────────────────────────────────────────────┤
│                                                        │
│  [جستجوی نام پزشک یا مرکز...]                         │
│  [کارت مرکز درمانی ۱]                                  │
│  [کارت مرکز درمانی ۲]                                  │
│                                                        │
├────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────┐  │
│  │ 🏥 نصب اپلیکیشن مراکز درمانی                [✕] │  │
│  │ دسترسی سریع، آفلاین و تمام‌صفحه بدون نوار آدرس   │  │
│  │ [ نصب مستقیم ]   [ شاید بعداً ]                  │  │
│  └──────────────────────────────────────────────────┘  │
│  [ خانه ]       [ نشان‌شده‌ها ]       [ راهنما ]      │
└────────────────────────────────────────────────────────┘
```

### استانداردهای طراحی بصری
* **پالت رنگی:** استفاده از رنگ آبی سازمانی کارآفرین (`#0a4c9a`) و پس‌زمینه با کنتراست ملایم (`#f2f5fa`).
* **انیمیشن‌ها:** ورود شناور بنر (`slide-up` نرم با ترنزیشن ۲۰۰ میلی‌ثانیه‌ای)، عدم تداخل با نوار تب پایین (`BottomNav`).
* **انطباق لبه‌های صفحه (Edge-to-Edge Safe Area):** پشتیبانی کامل از `env(safe-area-inset-bottom)` برای آیفون‌ها و گوشی‌های اندرویدی جدید.

## ۳. تصمیم‌های فنی و توازن‌ها (Key Product Decisions)

* **تصمیم ۱: مکانیسم شناسایی محیط Standalone**
  * *رویکرد:* بررسی دوگانه `window.matchMedia('(display-mode: standalone)').matches` و `navigator.standalone` در iOS.
  * *مزیت:* جلوگیری از نمایش هرگونه دکمه یا بنر مزاحم در زمانی که کاربر درون خود اپلیکیشن نصب‌شده حضور دارد.

* **تصمیم ۲: مدیریت حافظه رد کردن (Dismiss Cache)**
  * *رویکرد:* اگر کاربر دکمه بستن بنر را بزند، تا چند روز مجدداً بنر ظاهر نشود تا تجربه وبگردی مختل نشود، اما دکمه کوچک نصب در هدر همچنان به عنوان رزرو در دسترس بماند.

* **تصمیم ۳: سازگاری چند دامنه (Vercel Root vs GitHub Pages Subpath)**
  * *رویکرد:* استفاده از آدرس‌دهی هوشمند نسبی در `manifest.webmanifest` و تنظیم هدرهای شبکه در `vercel.json`.

## ۴. معماری فنی و جریان داده (Technical Architecture)

### دیاگرام جریان مؤلفه‌ها و مدیریت رخداد نصب

```
  ┌─────────────────────────────────────────────────────────┐
  │                   مرورگر کاربر (Client)                 │
  └────────────────────────────┬────────────────────────────┘
                               │
               beforeinstallprompt Event
                               │
                               ▼
  ┌─────────────────────────────────────────────────────────┐
  │                 usePWAInstall Hook                      │
  │  - ذخیره رویداد deferredPrompt                           │
  │  - سنجش وضعیت Standalone و پلتفرم iOS                   │
  └─────────────┬─────────────────────────────┬─────────────┘
                │                             │
    isInstallable = true               isIOS = true
                │                             │
                ▼                             ▼
  ┌───────────────────────────┐ ┌───────────────────────────┐
  │   PWAInstallBottomBanner  │ │   PWAInstallBottomBanner  │
  │   - کلیک روی «نصب سریع»   │ │   - کلیک روی «نصب آیفون»  │
  │   - اجرای prompt() بومی   │ │   - باز کردن راهنمای تصویری│
  └───────────────────────────┘ └───────────────────────────┘
                │                             │
                └──────────────┬──────────────┘
                               ▼
        ┌─────────────────────────────────────────┐
        │  اجرا در حالت کاملاً تمام‌صفحه         │
        │  (Standalone Web App / Full Screen)     │
        └─────────────────────────────────────────┘
```

### نیازمندی‌های فایل‌های اصلی در مرحله پیاده‌سازی
1. **کامپوننت جدید `PWAInstallBottomBanner.tsx`:** بنر شیک و شناور با استانداردهای Tailwind، عدم مسدودسازی BottomNav، کنترل رویدادهای لمسی.
2. **به‌روزرسانی `src/hooks/usePWAInstall.ts`:** اضافه کردن مدیریت Dismiss، ذخیره در LocalStorage و متدهای یکپارچه بازخورد.
3. **تنظیم فایل `vercel.json`:** تعریف مسیرهای SPA و هدرهای Cache-Control اختصاصی برای `sw.js` و `manifest.webmanifest`.
4. **تطبیق استایل بدنه (`index.html` و `App.tsx`):** اطمینان از تنظیم دقیق تگ‌های `apple-mobile-web-app-status-bar-style` و متای Viewport تمام‌صفحه.
